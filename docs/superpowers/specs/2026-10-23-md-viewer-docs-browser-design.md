# md_viewer 文档集阅读器 设计

日期：2026-10-23　状态：已实现（2026-10-23）
范围：`examples/md_viewer`（示例层），库不改

## 1. 背景与意图

维护者的典型场景：打开一套**多层目录**的文档，连续阅读其中的 `.md`；
对常看的文档做书签；需要时按**文件名/路径**或**正文里的一句话**快速定位。

现状 `md_viewer` 的侧栏是**单层平铺列表**（`QDir::Files`，不递归），
没有书签，也没有快速过滤。本次把它打磨成面向“文档集阅读”的产品形态，
仍然只读，不做编辑。

## 2. 目标 / 非目标 / 反目标

目标：

- 打开一个根目录后，侧栏展示**递归目录树**，只显示含 `.md` 的目录
- 文档级书签（星标），独立区块，跨会话持久化
- 双模式快速定位：文件名/路径过滤 + 跨文件全文搜索
- 全文结果点击后打开文档并**跳到命中位置**
- 记住上次打开的根目录、上次阅读的文档与**每篇文档的阅读位置**

非目标：

- 任何编辑、保存、实时预览、双链/标签/图谱
- 像素级复刻设计稿：Qt 控件与 CSS 稿在阴影/圆角/字宽上会有 1–2px 差异
- 背景图（阅读器皮肤）模式：已确认不做
- 跨根目录的全局搜索（只搜当前打开的根目录）
- 持久化全文索引（几百篇量级用流式扫描即可）
- 标题级/段落级书签（v1 只做文件级，后续可加）

反目标（即使做出来也算失败）：

- 全文搜索阻塞 UI（打开大文件的一次性卡顿可以接受，但必须先告知）
- 搜索不能取消，用户改主意后还要等扫完
- 书签/位置在重启后丢失或指向已删除文件时崩溃
- 点击搜索命中后跳到一个明显无关的位置（近似跳转允许漂移，但不许乱跳）

## 3. 约束与假设

- 规模：几百篇 `.md`；**单篇上限按 100MB 设计**（通常远小于此）
- 平台：Windows 主验证；Linux 可构建运行（WSL 已验证）
- 全部改动在 `examples/md_viewer`；`MarkdownView` 只用现有公开 API
  （`LoadFile`、`FindText`、`ScrollPosition`、`SetScrollPosition`、
  `renderFinished`、`outline`）
- 持久化沿用现有 `MdViewerSettings`（QSettings INI）

## 4. 交互与视觉设计

设计稿：`temp/ui-mockup/md_viewer_ui.html`（本地打开，含深色/亚克力/专注
状态与可点交互）。实现以稿子的布局、层级与交互为准，不追求像素级复刻。

### 4.0 窗口外观（FluentUI / QWindowKit）

- 无边框圆角窗口，沿用现有 `FluentTitleBar` 与窗口按钮
- 背景材质三档，默认 Mica：
  - Windows 11：`mica`（默认）/ `mica-alt`
  - 兼容档：`dwm-blur`
  - 更“厚”的半透明档：`acrylic-material`（QWindowKit 提供；Win10 与部分
    驱动上会退化，属已知差异）
- **单行标题栏**：菜单、导航、缩放、搜索全部并入，删除独立的菜单栏与
  工具条两行，垂直空间还给正文。从左到右：
  `图标 → 菜单按钮 → 文档名 → 后退/前进 → 缩放(−/100%/+) → 全局搜索 → 窗口按钮`
  - 菜单：一个汉堡按钮容纳原“文件/视图/帮助”三个子菜单，分组与全部
    快捷键保持不变；`QMenuBar` 不再安装
  - 导航与缩放：原工具条动作改成标题栏图标按钮，快捷键不变
  - 搜索框是入口，不另建搜索状态：聚焦/输入（Ctrl+K）即切到左栏
    “搜索”页签并执行同一份全文搜索
  - 窄宽度依次隐藏缩放组、搜索框、文档名，保留菜单与前进/后退
- 内容面板使用半透明 surface token（浅/深两套），保证 Mica 能透出
- **不做背景图模式**；“亚克力”只切换窗口材质，不引入图片
- 为支持单行标题栏，给 vendored FluentUI 打一个小补丁：
  - `FluentTitleBar::setLeadingWidget(QWidget*)`：图标之后注入（菜单按钮）
  - `FluentTitleBar::setTrailingWidget(QWidget*)`：搜索框之前注入（缩放组）
  - `FluentWindowFrame` 对新控件调用 `setHitTestVisible(..., true)`
  - 补丁记录：`patches/FluentUIStyle/0002-titlebar-widgets.patch`
  - 若不接受改 vendor，退路是保留两行（菜单栏 + 工具条），与设计稿有差异

### 4.1 左侧栏

一个 dock 内分三个区块（用可折叠分组或 tab，二选一在实现时定，
默认折叠分组更适合窄栏）：

1. **文档树**：根目录为根，目录可展开；只列出“子树中含 `.md` 或
   `.markdown`”的目录与文档文件；显示相对路径。忽略目录清单与全文搜索
   共用（树里同样跳过），保证“树里看到的 = 搜索能搜到的”。双击/单击打开（沿用现有单击行为）。
   树上方是**过滤框**：按文件名与相对路径做不区分大小写的即时过滤，
   输入时只隐藏不匹配项，不重建模型。
2. **书签**：星标文件列表，显示文件名 + 相对路径；右键可移除。
   当前文档的星标状态同步到工具栏/标题栏。
3. **搜索结果**：全文搜索命中，按文件分组，每组显示相对路径 +
   命中行片段（含关键词高亮）；点击命中项 → 打开文件并跳到该处。

侧栏底部状态：文件数、扫描进度（`已扫描 123/456`）、取消按钮。

### 4.2 打开与恢复

- “打开目录…”递归扫描。打开单文件时：若文件**位于当前根之下**，保持
  当前根不变；只有文件在根之外（或尚无根）时，才以其父目录为新根。
  这样从书签/搜索/最近列表打开子目录里的文件不会把树和搜索范围缩小。
- 启动时若上次根目录仍存在，自动打开并恢复上次文档与滚动位置；
  上次文档不存在则只加载树、不选中文档。没有保存过根目录时，沿用
  现有 `OpenLastFile()` 行为（打开最近存在的文件，以其父目录为根）；
  连最近文件都没有则显示空态。`root/dir` 在每次根变化时写入（包括
  单文件打开导致的换根）。
- 根目录变化用 `QFileSystemWatcher` 监听（已有依赖）：目录数 ≤200 时
  递归监听所有目录，超过则只监听根目录；监听事件 300ms 防抖后重建树
  （不做增量 diff）。始终提供“刷新”（F5）动作兜底。

### 4.3 书签

- 文件级：当前文档可一键星标/取消；星标集合**全局**，按绝对路径存储，
  同时记录星标时的根目录用于展示。
- 列表显示“文件名 + 相对路径”：文件在当前根下时相对当前根，否则相对
  星标时的根；两者都没有则显示绝对路径。
- 点击不在当前根内的书签只打开文件，**不改变当前根**（树保持不变），
  状态栏提示“该书签不在当前目录内”。
- 指向不存在的文件时保留条目但置灰，点击提示“文件已不存在”，
  提供“移除”操作。

### 4.4 全文搜索

- 触发：搜索框输入 ≥2 字符后 300ms 防抖；回车立即开始。
  每次新输入取消上一轮扫描。
- 匹配：**不区分大小写的字面量子串**（v1 不做正则/全词）。
- 文件类型：`.md` 与 `.markdown` 都算文档，树/过滤/搜索口径一致。
- 扫描：递归遍历根目录（**与文档树共用同一份忽略目录清单**：隐藏目录、
  `.git`、`node_modules`、`build*` 等）；对每个 `.md`/`.markdown`
  **流式逐行读取**
  （`QFile` 分块 + 行缓冲），单个 100MB 文件也不会整读进内存。
- 结果：按文件分组，每组最多 50 条命中，全局最多 2000 条；
  超出时在结果区显示“已截断”。结果**分批流式追加**，不是扫完一次性出。
- 取消与新查询的结果状态：**取消**保留已产生的部分结果，并标注
  “已取消（部分结果）”；**新查询**立即清空结果与进度，避免展示与
  查询不符的旧命中。
- 点击结果（近似跳转，已确认）：`LoadFile` → 等 `renderFinished` →
  按该命中在文件内的序号调用 `FindText` 前进到第 k 个**渲染文本**命中并
  选中；源码独有的命中（链接地址、注释等）会漂移到最近的可定位位置。
  一个渲染命中都找不到时，停在文档顶部并在状态栏说明。
- 视觉反馈：使用库的原生选中效果（选区颜色 + 滚动），**不做**稿子里的
  “整段闪光”；后者需要库提供源码位置到渲染节点的高亮 API，已评估为
  不值得（成本高、绑定 qlitehtml 内部结构）。

### 4.5 阅读位置

- 切换文档/关闭时记录该文件的 `ScrollPosition`（按绝对路径）；
  同一文件重开时恢复。
- 记录上限 500 条，LRU 淘汰；文件 mtime 变化超过阈值（例如文件已变）
  时仍恢复位置，但不做精确锚定（v1 用像素滚动位置）。

### 4.6 大文件（已确认：确认框 + 接受卡顿）

- 树中显示文件大小；用户主动打开 >20MB 的文档前弹确认
  （“该文档约 xx MB，渲染期间窗口可能无响应”）。同一文件每个会话只
  提示一次。
- 确认适用于用户主动打开的所有入口（树、对话框、拖放、书签、最近、
  搜索结果）；启动时的会话自动恢复不弹框，只在状态栏说明文件大小。
- 打开期间沿用现有“正在渲染…”占位页；库在 GUI 线程读取与解析，
  卡顿是已知限制，v1 不改库。

## 5. 架构与实现

### 5.1 新模块（examples/md_viewer）

- `document_index.{h,cpp}`：目录树扫描结果（相对路径、大小、mtime），
  只读数据 + 树模型构建；纯逻辑，可单测。
- `text_search.{h,cpp}`：全文扫描器。`QThread` + 原子取消标志，
  分批发出 `batchReady(files)` / `finished(truncated)` / `failed(error)`；
  扫描函数接受根目录、查询、忽略目录表。纯逻辑部分（行匹配、片段截取、
  截断规则）抽成自由函数，无 Qt GUI 依赖，可单测。
- `bookmarks.{h,cpp}`：书签集合的增删、持久化、失效路径标记。
- 复用 `MdViewerSettings` 增加键：`root/dir`、`session/last_file`、
  `session/positions`、`bookmarks/files`、`books/size` 等。

### 5.2 UI 改造

- `MdViewerWindow`：把 `QListWidget` 换成 `QTreeWidget`（或自定义模型）；
  新增过滤框、搜索框、结果视图、书签视图。
- 搜索扫描结果与 UI 通过信号槽跨线程传递（`QVector<SearchHit>` 注册元类型）。
- 打开大文件的确认框；恢复会话在窗口构造后、`show()` 前完成。

### 5.3 关键数据

```cpp
struct DocumentEntry {      // 树节点
  QString absolute_path;
  QString relative_path;
  qint64 size = 0;
  QDateTime modified;
  bool is_dir = false;
};

struct SearchHit {          // 单条命中
  QString file_path;        // 绝对路径
  QString relative_path;    // 相对根目录
  int line = 0;             // 1-based
  QString snippet;          // 命中行截断后的片段
  int match_offset = 0;     // 片段内关键词起点（用于高亮）
};
```

## 6. 性能与边界

- 名字过滤：几百个节点，直接在模型上过滤，目标 <16ms。
- 全文本扫描：磁盘 IO 主导；几百篇、总量 GB 级也可能耗时数秒到数十秒，
  因此必须**流式出结果 + 可取消 + 状态栏进度**。
- 100MB 单文件：逐行扫描不整读；命中片段有长度上限（例如 200 字符）。
- 并发：同一时刻只允许一个扫描任务；新任务开始前 join/取消旧任务。
- 已知限制（v1 接受）：源码独有命中跳转漂移；大文件打开时 GUI 线程
  卡顿；watcher 超过 200 个目录后退化为只监听根目录。
- 内存：结果集有硬上限（2000 条），不会随命中数量无限增长。

## 7. 错误与空态

- 根目录不存在/无权限：空态提示 + “重新选择目录”。
- 无 `.md`：空态提示（现有行为保留）。
- 扫描中文件被删除：跳过该文件，不中断整轮扫描。
- 书签指向失效文件：保留并置灰（见 4.3）。

## 12. 实现备注（2026-10-23）

- 侧栏采用 `QTabWidget`（文档 / 书签 / 搜索），没有用折叠分组；与原型一致。
- FluentUI 注入点补丁编号是 `0003-titlebar-widgets.patch`，因为 `0002` 已被
  ExWidgets 裁剪补丁占用。`FluentTitleBar` 新增
  `setLeadingWidget` / `setTrailingWidget` / `setTitleVisible`。
- Mica/亚克力只作用于窗口壳、标题栏和侧栏；正文仍由库的主题 CSS 决定，
  保持不透明。透明正文需要改库，本版不做。
- 标题栏搜索框成为全局搜索唯一入口：`Ctrl+K` 与 `Ctrl+F` 都聚焦它；原先的
  区分大小写/全词匹配/F3 查找动作移除。命中跳转仍用 `FindText` 近似定位。
- `OpenSearchHit` 用 `active_search_query_` 丢弃防抖窗口内旧扫描的排队信号；
  `TextSearch` 每轮再带一个请求 id，同一查询重开扫描时旧一轮的排队信号也不会混进新结果。
- funq 作为本地外部 GUI 冒烟工具（脚本在 `temp/ui-tests/`，不入库、不进 CI）：
  它能驱动标题栏、侧栏、树、书签和搜索结果，**不能**进入 qlitehtml 渲染窗口，
  正文选区与滚动位置仍由手工清单验证。
- watcher 监听所有未忽略的子目录（包括暂时没有 md 的空目录），这样往空目录里
  新建第一篇文档也会触发刷新；目录数超过 200 时仍退化为只监听根目录。
- 星标目标用 `displayed_file_`（`ShowFile` 已加载、可能还在渲染的文件），
  不用 `MarkdownView::current_file()`（要等 renderFinished 才提交）；星标按钮
  独立管理 checked/图标，不依赖 default action 的 changed 信号。书签右键菜单
  在 `exec` 前取出路径，避免刷新删 item 后的 use-after-free。阅读位置在渲染
  占位页期间不记录，避免把上一篇的位置写成 0。
- 验证：Windows VS2019 + Qt 5.15.2 x86，`ctest -L MARKDOWN` 25/25 通过；
  其余矩阵交给 GitHub CI。

### 12.1 原型对齐（2026-10-23）

- 大纲从左侧 dock 移到正文右侧 212px 独立列；窗口窄于 980px 时自动
  收起，用户手动关掉的状态不会被自动弹开。
- 侧栏固定为 278–320px；文档树、书签、搜索结果都改成单列自绘：
  - 文档树：文件夹/文件图标、目录子树篇数、文件大小、行内星标（点击
    切换收藏）；文件大小仍保留，原型只有目录计数。
  - 书签：实心星 + 文件名 + 相对路径的双行卡片，失效项置灰。
  - 搜索结果：圆角卡片 + 行号 + 黄色 mark；正文选区仍由 `FindText`
    决定，无法统一成黄色。
- 页签用 FluentUI 的 `Segmented_Slide`（`TabBarStyleProperty`）加
