# md_viewer 现代阅读器设计

日期：2026-10-24
分支：`feature/modern-reader`
状态：实施中

## 目标

在不引入浏览器核心的前提下，把 `md_viewer` 做成一个现代、精美、键盘
优先、适合长时间阅读的 Qt Widget Markdown 查看器。渲染仍然由 qlitehtml
+ md4c + 原生公式/Mermaid 后端完成；改动集中在宿主层，库只做必要的
小步扩展。

## 体验原则

1. 打开即有明确去处：没有文档时不是空白页，而是可操作的欢迎页。
2. 键盘优先：文件、标题、命令都能用一个面板到达。
3. 阅读区可调：字号、行距、栏宽属于读者，不属于应用。
4. 长文有位置感：顶部进度线、浮动回顶按钮、状态栏阅读时间。
5. 图表可细看：图片/公式/Mermaid 用沉浸式灯箱，而不是普通对话框。

## 选定功能

### 1. 快速跳转（Ctrl+P）

一个居中的浮动面板，同一输入框搜索四类目标：

- 当前文档标题（跳锚点）
- 当前文档集文件（跳文件）
- 最近打开（跳文件）
- 命令（打开文件/目录、切主题、专注模式、收藏、导出、刷新、缩放）

匹配规则：大小写不敏感的子序列匹配；标题权重高于副标题；连续命中与
词首命中加分；空查询按“标题 → 最近 → 命令 → 文件”的固定顺序展示，
命令排在文件前，避免文档多时被结果上限截掉。键盘：输入即筛选，↑/↓
选择，Enter 执行，Esc 关闭。

实现为独立模块 `quick_open.{h,cpp}`：纯函数负责打分与排序，弹出层只负责
展示与键盘。这样逻辑可以无头测试。

### 2. 阅读外观（标题栏 Aa）

弹出面板提供三组选项：

- 字号：小 13 / 标准 15 / 大 17 / 特大 19
- 行距：紧凑 1.6 / 标准 1.78 / 宽松 2.0
- 栏宽：默认 / 窄 680 / 舒适 760 / 宽 900 / 全宽

选择立即生效并持久化。CSS 以追加方式注入：原件样式保持不变，偏好只覆盖
`body` 的字号/行距与正文栏宽。为此给库增加
`MarkdownView::AppendThemeStyleSheet(theme, css)`——与现有的“整份替换”
`SetThemeStyleSheet` 分开，避免宿主为了改字号不得不复制一份完整主题。

栏宽对两种阅读样式的落点不同：

- 原型样式：限制标题/正文/列表/引用块（媒体保持全宽）
- 库默认样式：限制 `.md-page`

默认偏好为空，不注入任何 CSS，行为与现在完全一致。

### 3. 欢迎页

没有已提交文档时显示：

- 应用图标与一句定位文案
- 主按钮“打开目录”，次按钮“打开文件”
- 最近文档列表（最多 5 条，点击打开）
- 快捷键提示：Ctrl+K 搜索、Ctrl+P 快速跳转、Ctrl+Shift+F 专注模式

欢迎页放在阅读容器内，与正文互斥显示；开始渲染新文档时立即切回正文的
“正在渲染…”占位页。

### 4. 阅读进度与回顶

- 阅读区顶部 2px 进度线，按 `scroll / (documentHeight - viewportHeight)`
  计算；换文档/重排后归零。
- 浮动圆形“回到顶部”按钮，滚动超过一屏后出现，点击平滑回顶。
- 状态栏增加“约 N 分钟”阅读时长（按源字符数估算，中文约 500 字/分钟）。

库为此增加 `MarkdownView::DocumentHeight()` 与 `ViewportHeight()` 两个只读
访问器；qlitehtml 已有 `documentHeight()`，不涉及渲染逻辑。

### 5. 图片灯箱

把现有 `ImagePreviewDialog` 升级为覆盖主窗口的沉浸式灯箱：

- 半透明深色背景，图片居中，滚轮缩放、拖动平移、双击切换适应/100%
- 顶部工具条：适应窗口、100%、查看源码（公式/Mermaid）、另存为、关闭
- 底部提示：滚轮缩放 · 拖动平移 · Esc 关闭

普通图片与公式/Mermaid 共用；源码与另存为动作复用宿主现有实现。

## 非目标

- 不引入 WebEngine/CEF，不改变“原生 QWidget 渲染”的定位。
- 不做多标签页：现有目录树、历史栈与快速跳转已经覆盖跨文档导航，
  多标签会显著增加状态复杂度，收益有限。
- 不做在线同步、账号、注释协作。
- 不修改 md4c 语法集；本轮的增强都在展示与导航层。

## 技术方案

新增示例层模块（均不依赖 qlitehtml 类型）：

| 文件 | 职责 |
|---|---|
| `quick_open.h/.cpp` | 快速跳转的条目模型、模糊匹配、弹出层 |
| `reader_appearance.h/.cpp` | 阅读偏好结构、CSS 生成、外观弹出层 |
| `welcome_view.h/.cpp` | 欢迎页、最近文档、快捷键提示 |
| `reading_progress.h/.cpp` | 顶部进度线、回顶按钮的容器控件 |

库改动：

- `MarkdownView::AppendThemeStyleSheet(theme, css)`
- `MarkdownView::DocumentHeight()` / `ViewportHeight()`

设置键：

- `reading/font_size`（int，0 = 默认）
- `reading/line_height_percent`（int，0 = 默认）
- `reading/measure_px`（int，-1 = 默认，0 = 全宽）

## 测试

- 纯函数：模糊匹配排序、空查询顺序、上限；阅读偏好 CSS 的各组合。
- 控件：快速跳转输入筛选与 Enter 激活；欢迎页最近列表与信号；
  阅读偏好弹出层的按钮状态。
- 库：追加样式生效且不覆盖原主题；文档高度/视口高度非负。
- 全部测试使用 offscreen，归入 `MARKDOWN` 标签。
