title: "基于 AI Agent 的知识库 V1" date: 2026-11-18 type: 知识库 tags: [daily] mood: productive highlights: - "开始正规知识库的好处了" - "完成了知识库初始化脚本"

基于 AI Agent 的知识库 V1

写了一个脚本来初始化一个目录。快速做好目录雏形，然后收集资料，提示 AI Agent 分析整理，然后再自己整理。

1. 脚本

新建一个 ps1 文件，贴以下内容：

PowerShellUTF-8
#Requires -Version 5.1
$ErrorActionPreference = 'Continue'

Write-Host "================================================"
Write-Host "项目初始化脚本"
Write-Host "当前目录: $PWD"
Write-Host "================================================"

# ===== 用户确认 =====
Write-Host ""
Write-Host "按 Enter 确认在当前目录初始化，按 Esc 退出..."
do { $k = [Console]::ReadKey($true) } while ($k.Key -ne 'Enter' -and
       $k.Key -ne 'Escape')

2. 操作

脚本只负责把目录骨架建起来，真正的知识沉淀仍然靠后面的日常采集与周期性整理。

  • 新建主题目录，保持一层结构，避免分类过深。
  • 把原始资料先放进 inbox，不做即时分类。
  • 每周把 inbox 交给 Agent 做一次归并，再人工确认。

3. 怎么用？

3.1 第一次打开：初始化配置

选择工作区根目录，确认模板、索引文件与采集目录的位置。初始化完成后，侧栏会自动显示文档树。

3.2 日常采集：只做“扔进去”

看到值得留下的内容，先放进 raw/inbox。不要在采集阶段做分类，分类会打断阅读。

3.3 AI 整理：把 Raw 喂给 Agent

把一批 raw 文档连同标签一起交给 Agent，让它输出候选主题和引用关系，再由人做最终取舍。

3.4 产出：从 Wiki 到 Outputs

稳定的主题进入 wiki，面向外部的内容再进入 outputs。两者不混在一起。

3.5 周期性回顾：别让 Raw 变成垃圾场

每周固定一次回顾，把无法归并的条目删掉或退回采集池。

3.6 一句话流程

采集 → 归并 → 确认 → 沉淀 → 输出。
